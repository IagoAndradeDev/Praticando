# Projetos de Prática

Projetos desenvolvidos por iniciativa própria, com o objetivo de aprender na prática e colocar em uso os conhecimentos adquiridos durante os estudos.

Aqui, a ideia é **aprender fazendo** desenvolver projetos mesmo quando ainda existem dúvidas, pesquisando informações, testando soluções e utilizando IA como ferramenta de apoio para entender conceitos e tirar duvidas.

Nem sempre o código da certo de primeira, mas cada projeto serve como uma aprendizado buscando aprender, errar, pesquisar e melhorar.

> **Aprendendo na prática, pesquisando problemas, tirando dúvidas e construindo conhecimento através de alguns projetos.**
